# API

FastAPI admin server with Jinja2 templates for PINN knowledge base management.

## Quick Start

```bash
uv run pinn-admin
```

Then open http://localhost:8000 and log in with `admin` / `admin`.

## Features

- Collection management with access control (public/restricted + group-based)
- Document upload, indexing, search, and deletion
- Bootstrap 5 admin dashboard
- Session-based authentication
